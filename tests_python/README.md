\# MaxWinUCRT\_kaldi\_Vosk\_dll



Портативная сборка \*\*Vosk API\*\* для Windows, скомпилированная с использованием тулчейна \*\*MSYS2 UCRT64\*\*. 

Этот проект предоставляет самодостаточный Python Wheel, который не требует предустановленного окружения MSYS2 или сторонних рантаймов.



\## 🚀 Основные особенности

\* \*\*UCRT64 Runtime\*\*: Современная библиотека C от Microsoft.

\* \*\*Fully Static\*\*: Минимизированы внешние зависимости (все критичные библиотеки включены в пакет).

\* \*\*Python 3.11+ Support\*\*: Проверено на Python 3.14.

\* \*\*Optimized\*\*: Включает поддержку OpenBLAS для ускорения вычислений.
